# Icons

Lucide icons (ISC license), 24px grid. The files are the originals: `stroke="currentColor"` at stroke width 2, which renders black when shown as an image. In the product, draw them with the `Icon` component, which uses a 1.75 stroke and inherits the text color (`ink`, `ink-muted`, `signal`, or a status or severity color).

- `shield-check`: verified ownership, passed checks.
- `shield-alert`: security issues found.
- `scan-search`, `scan-line`, `radar`: scans and scanning.
- `bug`: findings, vulnerabilities.
- `globe`: websites and domains.
- `server`: hosts, ports and services.
- `folder-git-2`, `git-branch`: repositories and branches (code scanning).
- `file-code`: a source file or a code location.
- `file-lock-2`, `key-round`, `lock`: secrets, keys and TLS.
- `octagon-alert`, `triangle-alert`, `info`, `circle-check`, `circle-x`: danger, warning, info, success and failure in alerts and statuses.
- `clock`: queued, pending, scheduled.
- `copy`, `external-link`, `refresh-cw`, `settings`, `log-out`: common actions.
