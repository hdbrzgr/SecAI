# ScoreGrade

The overall result of a scan: a letter grade and a score out of 100. A and B read `pass`, C `warning`, D and F `danger`.

## Props
- `grade` (required): `"A" | "B" | "C" | "D" | "F"`.
- `score` (required): 0–100.
- `label`: the eyebrow, default "Security grade".
- `caption`: one line of context ("Up 6 since last week").
