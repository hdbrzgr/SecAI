# Wordmark

The SecAI name set in type: "Sec" in `ink`, "AI" in `signal`, IBM Plex Sans Condensed Bold. SecAI has no drawn logo.

## Props
- `size`: font size in px, default 20. Use 20 in the header and 32 or more on auth and marketing pages.

## Do and don't
- Always write the name as SecAI, one word, with capital S, A and I.
- Don't add a shield, lock or eye symbol beside it.
